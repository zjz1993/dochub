# Proposal

## Why

一篇文档要有多份语言版本，每份有自己的标题和草稿，独立发布。正文是编辑者用富文本编辑器写的 HTML，直接渲染就是存储型 XSS 的入口，必须在保存时净化。文档里的图片还需要上传和访问。

## What Changes

- 语言版本：在文档下新建，预填默认语言的内容；补上“新建文档时同时创建默认语言版本”。
- 保存草稿：标题和正文，正文按白名单净化后保存。
- 图片上传与访问：类型和大小校验、随机文件名、防路径穿越；存储方式藏在接口后面。
- 目录树里的文档从此有标题。

## Capabilities

### New Capabilities
- `file-management`: 文档正文里图片的上传、存储与访问

### Modified Capabilities
- `document-management`: 新增语言版本、草稿保存与净化、读取语言版本等需求；新建文档时同时创建默认语言版本

## Impact

- 新增表 `language_version`。
- 新增 `content/`、`file/` 两个包；`AccessChecker` 增加按语言版本判断的方法。
- 引入 Jsoup。文件存储目录由环境变量配置，容器部署时挂载为数据卷。
- 保存草稿此刻不需要编辑锁。锁在下一个变更加入，并给这个接口加上持锁校验。
- 对应第 5 周，学习重点：存储型 XSS 与白名单净化、文件上传安全、派生数据。见 `docs/learning/week-05.md`。
