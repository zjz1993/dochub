## 1. 语言版本

- [ ] 1.1 **语言版本表设计**（1.5h｜你设计｜前置：任务 3.1（`add-category-tree-and-documents`））：自己设计 `language_version`，对照 `docs/database-conventions.md` 的表设计，写 `V5`。 验证：同一文档同一语言只能有一个语言版本；你能解释线上内容为什么不直接存在这张表里。
- [ ] 1.2 **新建语言版本与预填**（1.5h｜你写｜前置：任务 1.1、任务 3.1（`add-category-tree-and-documents`））：在文档下新建语言版本；校验语言合法、不重复；预填默认语言版本的内容（有已发布内容用已发布，否则用草稿）。补上任务 3.1（`add-category-tree-and-documents`）留的 TODO：新建文档时，在同一个事务里创建文档和它的默认语言版本，标题必填。 验证：重复创建返回 409；预填内容来自正确的来源；新建文档后默认语言版本同时存在。 测试：2 条集成测试

## 2. 草稿

- [ ] 2.1 **保存草稿与 HTML 净化**（3h｜你写（重点）｜前置：任务 1.2）：保存草稿接口（标题、正文）；用 Jsoup 的 `Safelist` 白名单净化正文。先从 Textory 导出各类节点的真实 HTML 当样本（标题、列表、任务列表、表格、代码块、图片、链接、颜色与对齐），按样本确定白名单，把样本存成测试夹具；记录 `draft_updated_at`。 验证：`<script>`、`onerror` 属性、`javascript:` 链接被清除；表格、代码块、图片、任务列表原样保留。 测试：净化的单元测试至少 5 条，每条一个样本

## 3. 图片

- [ ] 3.1 **图片上传与访问**（2.5h｜你写｜前置：任务 3.2（`add-engineering-foundation`））：上传接口（multipart）；校验类型和大小，拒绝 svg；定义 `FileStorage` 接口和本地磁盘实现（按年月分目录，UUID 文件名）；访问接口防路径穿越，并加 `X-Content-Type-Options: nosniff`。 验证：上传后返回的 URL 能访问；svg 或超限文件返回 400；构造带 `../` 的路径拿不到文件。 测试：2 条集成测试
