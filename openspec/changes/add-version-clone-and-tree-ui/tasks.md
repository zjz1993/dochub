## 1. 复制版本

- [ ] 1.1 **复制版本设计**（1.5h｜你在纸上设计｜前置：任务 2.2（`add-document-publishing`））：写出插入顺序（版本 → 分类，先父后子 → 分类名 → 文档 → 语言版本 → 修订）；新旧 id 映射表怎么建；译文的过期指针怎么映射；哪些东西不复制（编辑锁、线上修订之外的历史修订）。 验证：设计经审查通过后再写代码。
- [ ] 1.2 **复制版本实现**（4.5h｜你写（全项目最复杂的任务）｜前置：任务 1.1）：在一个事务里完成整版复制；新版本为未上线；有线上内容的语言版本各生成一条“复制”修订并指过去；复制来的草稿不算“有未发布修改”；译文的过期状态与原版本一致。 验证：复制后两个版本的结构和内容一致；译文的过期状态与原版本一致；复制后新版本是未上线。 测试：3 条集成测试（结构一致、内容一致、指针映射）

## 2. 目录树管理页与版本统计

- [ ] 2.1 **目录树管理页**（2.5h｜AI 写，你联调｜前置：任务 2.3（`add-document-publishing`））：左侧目录树，支持分类与文档的增删改、拖拽排序和移动；状态标记（无语言版本、草稿、已发布、有未发布修改、被锁定、译文过期）；按语言编辑分类名称的弹窗。 验证：拖拽后顺序已保存；非法移动有明确提示；状态标记与接口返回一致。
- [ ] 2.2 **复制入口与版本统计**（1.5h｜AI 写，你联调｜前置：任务 1.2、任务 2.1）：版本列表加“复制为新版本”入口和确认框；版本列表补上文档数和未发布修改数；手测“复制 → 修改 → 发布”。 验证：复制一个有内容的版本后，新版本在目录树页里的内容和状态与原版本一致。
