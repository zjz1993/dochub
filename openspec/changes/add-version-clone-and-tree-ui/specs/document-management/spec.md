# Spec Delta

## ADDED Requirements

### Requirement: 目录树管理页
管理端 SHALL 提供目录树页面。成员可以在页面上完成分类和文档的新建、改名、删除、拖拽排序和移动，并按语言编辑分类的名称。

#### Scenario: 拖拽排序
- **WHEN** 成员把一个文档拖到同一个分类下的另一个位置
- **THEN** 刷新页面之后，文档停在新的位置

#### Scenario: 拖拽到非法的位置
- **WHEN** 成员把一个分类拖到它自己的子分类之下
- **THEN** 页面提示无法移动，树恢复成原来的样子

#### Scenario: 按语言编辑分类名称
- **WHEN** 成员打开分类的编辑弹窗，补上英文名称并保存
- **THEN** 目录树在所选语言下显示对应的名称

### Requirement: 目录树上的状态标记
目录树 SHALL 为每个文档的每个语言版本显示状态：没有语言版本、草稿、已发布、有未发布修改、被锁定、译文过期。

#### Scenario: 状态与接口一致
- **WHEN** 某个语言版本被他人锁定，另一个译文已经过期，还有一个有未发布的修改
- **THEN** 页面上这三个语言版本分别显示“被锁定”“译文过期”“有未发布修改”，与目录树接口返回的字段一致
