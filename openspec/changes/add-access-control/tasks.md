## 1. 数据模型

- [ ] 1.1 **用户、产品线与成员表设计**（1.5h｜你设计并写迁移｜前置：任务 4.1（`add-engineering-foundation`））：先不看 `docs/database-conventions.md` 里的表设计，自己画出 `app_user`、`product_line`、`user_product_line` 的字段、主键、唯一约束、外键；再对照 `docs/database-conventions.md` 的表设计 找差异；写 `V2`。成员表要引用产品线，所以产品线表在这里一起建。 验证：重复用户名插入失败；你能解释成员表为什么用联合唯一。

## 2. 登录与令牌

- [ ] 2.1 **密码加密与登录接口**（1.5h｜你写｜前置：任务 1.1）：`POST /api/admin/auth/login`；用 BCrypt 存储和校验密码；用户不存在与密码错误返回同一提示；被禁用的用户不能登录。 验证：库里存的是 BCrypt 串；两种失败返回相同的提示。 测试：2 条单元测试（成功、密码错误）
- [ ] 2.2 **JWT 签发与解析**（1.5h｜你写｜前置：任务 2.1）：`TokenService`，用 HS256 签发，载荷放用户 id 和角色；解析时校验签名和过期；密钥来自配置，至少 32 字节。 验证：篡改载荷或签名后解析失败；过期令牌解析失败。 测试：3 条单元测试

## 3. 请求安全

- [ ] 3.1 **Spring Security 接入**（2.5h｜你写（本周重点）｜前置：任务 2.2）：配置 `SecurityFilterChain`：不建会话，`/api/portal/**`、`/files/**`、健康检查放行，其余需要登录。写 `TokenAuthFilter`：从 Cookie 读令牌，每次请求查一次用户（禁用立即生效），设置认证信息。登录成功写入 httpOnly Cookie（`SameSite=Strict`，生产环境加 `Secure`）。未登录和无权限返回统一 JSON；登出清 Cookie。 验证：不带 Cookie 访问 `/api/admin/locales` 返回 401，带 Cookie 返回 200；浏览器 JS 读不到这个 Cookie；禁用用户后下一次请求就是 401。 测试：3 条集成测试（401、200、禁用后 401）

## 4. 用户与成员管理

- [ ] 4.1 **用户管理与成员分配**（1.5h｜你写 Service，AI 写 Controller 与 DTO｜前置：任务 3.1）：用户的分页查询、新增、修改、重置密码、启用禁用、分配产品线；只允许系统管理员，用方法级鉴权限制；不能禁用或降级自己。 验证：编辑调用用户管理接口返回 403；系统管理员不能禁用自己。 测试：2 条集成测试（管理员可建用户；编辑 403）
- [ ] 4.2 **开发与测试用的种子数据**（1.5h｜AI 写，你读｜前置：任务 4.1）：只在 dev 环境生效的初始化器（1 个系统管理员、2 个编辑、2 条产品线）；测试里的登录辅助方法，一行拿到某个用户的 Cookie。 验证：dev 启动后能用种子账号登录；换成 prod 启动不会产生任何账号。 测试：辅助方法被任务 3.1、任务 4.1 的测试使用
