## 2. 分类树

- [ ] 2.1 **分类增删改与目录树查询**（3h｜你写｜前置：任务 1.1）：新增分类（必须带默认语言的名称）；按语言改名称；删除（必须为空）。目录树接口：一次查出某版本的全部分类和文档，在内存里组装成树并排序。文档的标题存在语言版本里，那张表第 5 周才建，所以这一周树里的文档暂时只有 id。 验证：树的嵌套和顺序正确；删除非空分类返回 409。 测试：树的组装与排序写 2 条单元测试；1 条集成测试
- [ ] 2.2 **分类移动与排序**（2h｜你写｜前置：任务 2.1）：把分类移到新的上级分类并指定位置；校验目标在同一版本，且不能移到自己或自己的子孙下面；移动后重排同级的顺序。 验证：把“产品简介”移到自己的子分类下返回 400；正常移动后树正确。 测试：2 条单元测试（环检测）

## 3. 文档

- [ ] 3.1 **文档增删、移动**（2h｜你写｜前置：任务 2.1）：新建文档（生成 `doc_key`，这一周只建文档本身）；移动到别的分类并排序；删除（先实现直接删除）。“新建时同时建默认语言版本”在任务 1.2（`add-language-versions-and-drafts`）补上，“没有任何已发布的语言版本才允许删除”在任务 2.1（`add-document-publishing`）补上，两处都留 TODO。 验证：新建后文档出现在目录树对应分类下；移动后顺序正确。 测试：1 条集成测试
