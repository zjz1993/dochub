# 领域模型

企业级产品文档管理与发布平台。软件公司用它管理多条产品线、多个产品版本、多种语言的文档，并向最终用户展示已发布的内容。

本文件是术语表加业务规则。**术语以这里为准**：和代码变量名、接口名不一致时，先改这里再改代码。表结构见 [database-conventions](./database-conventions.md)。

## 术语表

### 内容结构

**产品线 (Product Line)**:
公司对外的一个产品，例如“数据分析平台”。一个产品线包含多个产品版本。
_Avoid_: 产品（单独使用）、系统、项目

**产品版本 (Product Version)**:
产品线的一次对外发布，例如 `2.0.0`、`2025`、`v3`。每个产品版本拥有自己完整且相互独立的一套文档。
_Avoid_: 版本（单独使用）、文档版本

**分类 (Category)**:
产品版本内、位于文档上方的分组节点，可以多层嵌套，本身没有正文。
_Avoid_: 目录、文件夹、章节

**文档 (Document)**:
最小的不可再分的内容单元，例如「FineReport产品简介」，归属于一个分类。
_Avoid_: 页面、文章

### 国际化

**语言版本 (Language Version)**:
一篇文档在某一种语言下的那份内容，例如「FineReport产品简介」的 zh-CN 版和 en-US 版。
_Avoid_: 翻译版本、版本（单独使用）

**默认语言 (Default Language)**:
每个产品线配置的一种语言，例如 zh-CN。读者所需的语言没有已发布内容时，以默认语言的内容为准。
_Avoid_: 主语言、原始语言

**原文 (Source)**:
对一篇文档的某个语言版本而言，同一篇文档的默认语言版本。
_Avoid_: 源语言、源文档

**译文 (Translation)**:
默认语言之外的语言版本，例如 zh-CN 为默认语言时的 en-US 版和 ja-JP 版。
_Avoid_: 翻译（作名词时）、译本

**过期 (Outdated)**:
译文已发布，但它发布时依据的那条原文修订不再是原文的线上修订时，译文所处的状态。
_Avoid_: 失效、需要更新

### 发布

**草稿 (Draft)**:
一个语言版本正在编辑的内容，只有管理端能看到。
_Avoid_: 编辑中内容、未发布内容

**已发布内容 (Published Content)**:
一个语言版本最后一次发布出去的内容，读者能看到的只有它。
_Avoid_: 正式内容、线上版本

**发布 (Publish)**:
用一个语言版本的当前草稿替换其已发布内容的动作，一次只针对一个语言版本。
_Avoid_: 上线、提交

**上线 (Go Live)**:
让一个产品版本开始对读者可见的动作。版本上线后，其中已发布的语言版本才能被读者看到。
_Avoid_: 发布（指产品版本时）、启用

**下线 (Take Offline)**:
让内容停止对读者可见：对语言版本是撤回其已发布内容，对产品版本是整个版本不再出现在展示端。
_Avoid_: 取消发布、撤回、删除

### 修订

**修订 (Revision)**:
一个语言版本在某次发布时的内容快照，写入后不再修改。
_Avoid_: 历史版本、修订版本、版本（单独使用）

**回滚 (Rollback)**:
把一个语言版本的线上内容指向更早一条修订的动作，立即对读者生效。
_Avoid_: 恢复、撤销

### 编辑

**编辑锁 (Edit Lock)**:
对一个语言版本的排他编辑权，同一时刻只有一个用户持有，持有者不再操作后自动失效。
_Avoid_: 编辑权限、占用、加锁

### 权限

**系统管理员 (System Administrator)**:
负责整个系统的角色：管理产品线、产品版本和用户，可以操作所有内容。
_Avoid_: 超级管理员、超管

**编辑 (Editor)**:
只负责内容维护的角色，只能操作自己被分配到的产品线，不能管理产品线、产品版本和用户。
_Avoid_: 作者、贡献者

**产品线成员 (Product Line Member)**:
被分配到某个产品线的编辑。
_Avoid_: 产品线负责人、产品线角色

### 入口

**管理端 (Admin Console)**:
供公司内部人员（系统管理员、编辑）使用的部分，需要登录，能看到草稿和已发布内容。
_Avoid_: 后台、CMS

**展示端 (Portal)**:
供读者使用的部分，无需登录，只展示已上线版本的已发布内容。
_Avoid_: 前台、门户、官网

**读者 (Reader)**:
展示端的访问者，没有账号，只阅读已发布内容。
_Avoid_: 用户、访客

## 核心实体

| 实体 | 是什么 | 归属 |
|---|---|---|
| `locale` | 语言字典 | 系统 |
| `app_user` | 系统管理员和编辑 | 系统 |
| `product_line` | 产品线 | 系统 |
| `user_product_line` | 编辑被分配到哪些产品线 | — |
| `product_version` | 产品版本，每个版本有独立的上线状态 | 产品线 |
| `category` | 分类，自引用成树 | 产品版本 |
| `category_name` | 分类在各语言下的名称 | 分类 |
| `document` | 文档的身份，带一个跨版本稳定的 `doc_key` | 产品版本、分类 |
| `language_version` | 语言版本：草稿在这里，线上内容指向一条修订 | 文档 |
| `revision` | 修订：发布时的内容快照，写入后不再修改 | 语言版本 |

## 状态与流转

| 对象 | 状态 | 流转 |
|---|---|---|
| 产品版本 | 未上线、已上线 | 未上线 ↔ 已上线，由系统管理员切换；只有已上线的版本对读者可见 |
| 语言版本 | 未发布、已发布 | 发布：未发布 → 已发布；下线：已发布 → 未发布。每次发布产生一条修订 |
| 编辑锁 | 未持有、被持有 | 获取、续期、释放、过期，见 ADR-004 |

“版本”一词只用于产品版本。“修订”是发布时的内容快照，不是版本。

## 派生状态

这些状态不单独存字段，由已有数据算出来。规则集中写在一处，并且都有单元测试。

| 状态 | 规则 |
|---|---|
| 语言版本已发布 | `published_revision_id` 不为空 |
| 有未发布修改 | 已发布且 `draft_updated_at` 晚于 `published_at`；或未发布且草稿正文非空 |
| 译文过期 | 该语言版本不是默认语言，且原文（默认语言版本）的 `published_revision_id` 非空，并且不等于本语言版本的 `translated_from_revision_id` |
| 文档在展示端可见 | 至少有一个语言版本已发布 |
| 读者看到的内容 | 所需语言的已发布内容；没有则默认语言的已发布内容并标记 `fallback`；都没有则取任意一种已发布的语言；一种都没有则 404 |
| 分类在展示端可见 | 自己或子孙分类下有可见的文档 |

## 业务规则

| 主题 | 做法 |
|---|---|
| 分类 | 可以多层嵌套，层数不限；挂在产品版本下，随版本一起复制 |
| 默认语言 | 配置在产品线上；创建分类和文档时必须有默认语言的名称和标题 |
| 语言字典 | 系统级，迁移脚本预置 zh-CN、en-US、ja-JP，MVP 不做管理界面 |
| 译文过期 | 只看已发布内容；只是标记，不阻止发布；重新发布译文即清除 |
| 新建语言版本 | 预填默认语言的内容，已发布优先，其次草稿 |
| 复制版本 | 不复制修订历史和编辑锁；每个有线上内容的语言版本带一条“复制”修订 |
| 版本删除 | 只允许删除未上线且没有任何文档的版本 |
| 产品线删除 | 不提供，用停用代替 |
| 编辑锁 | 粒度是语言版本；被锁时只能查看并显示持有者；不做强制接管 |
| 发布的最小单位 | 一个语言版本 |
| 展示端的可见性 | 文档至少有一个语言版本已发布才出现在目录树；空分类不显示 |
| 展示端地址 | `/{产品线code}/v{版本id}/{docKey}?locale=`，同一篇文档在不同版本里 `docKey` 相同 |
| 登录态 | httpOnly Cookie，8 小时；登出后旧令牌在到期前仍然有效 |
| 图片 | 存在服务器本地目录；不允许 svg；单张不超过 10MB |
| 展示端渲染 | 后端只返回净化后的 HTML 和标题；前端渲染时再净化一次 |
| 登录与权限 | 系统管理员不能禁用或降级自己；编辑没有被分配任何产品线时，管理端显示空状态 |
| 部署 | 子域名 `dochub.zhaojunzhe.site`；主域名继续放你的博客 |
