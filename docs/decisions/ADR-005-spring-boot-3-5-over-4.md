# 用 Spring Boot 3.5 而不是 4.x

2026 年 11 月启动这个项目时，Spring Boot 4.x 已经发布一年，3.5.16 是 3.x 的最后一个小版本，开源支持在 2026-06-30 结束。我们仍然决定用 3.5.16（配 JDK 21），并把“迁移到 4.1”列为 MVP 之后的练习。

## 理由

DocHub 的首要目标是让作者在 12 周内补齐后端基本功，而不是长期承载生产流量。3.x 的教程、问答和 AI 辅助都远比 4.x 充分，MyBatis-Plus、springdoc 等依赖在 Boot 3 上也最成熟。4.x 的模块拆分更细，依赖名和配置有调整，照 3.x 的教程做会反复踩坑。

## 后果

- 3.5.16 不会再有开源安全补丁。项目可以用于学习和作品展示，但在对外长期承载数据之前必须升级。
- “迁移到 Spring Boot 4.1”是有意保留的后续任务，不是遗漏。
